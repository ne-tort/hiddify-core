# Pathology Core

Native proxy core used by [Pathology](https://github.com/ne-tort/pathology-app)
(Sing-box based). This directory is part of the app repository.

License: see [LICENSE.md](./LICENSE.md) and the app-level [NOTICE.md](../NOTICE.md)
(upstream attribution to Hiddify Next under GPL-3.0).

## Build (Windows)

```bat
build_windows.bat
```

## Notes

- Previously known as Hiddify Core when this project was based on
  [hiddify/hiddify-app](https://github.com/hiddify/hiddify-app).
- Standalone installer / Docker flows from upstream Hiddify are not maintained here;
  build via the app scripts (for example `scripts/build_cp_windows.ps1`).
